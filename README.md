# 🎬 下町きろく 管理ダッシュボード

下町きろくの動画屋サイト更新を簡単にするための管理ツールです。

**👉 使い方は [使い方.md](./使い方.md) をご覧ください。**

`start.bat`（Windows）または `start.sh`（Mac）をダブルクリックするだけで起動します。

## ✨ 機能

- 🖼️ サイトプレビュー - 現在のサイトをリアルタイムで確認
- 📤 画像アップロード - ドラッグ&ドロップで複数画像を一括アップロード
- ✏️ コンテンツ編集 - HTMLファイルをダイレクト編集
- 📁 ファイル管理 - 全ファイルの確認と管理
- 🚀 ワンクリック更新 - FTP情報を保存してさくらインターネットへ自動アップロード
- 🔒 セキュア設定 - パスワードは暗号化して保存

## 🔧 ファイル構成

```
shitamachi-web/
├── 使い方.md               ← まずはここを読んでください
├── start.bat               ← Windows起動用（ダブルクリック）
├── start.sh                ← Mac起動用（ダブルクリック）
├── server.js                # Express サーバー（バックエンド）
├── src/                      # ダッシュボードのReactコード
├── index.html, menu.html...  # 実際のサイトファイル
```

## 🔐 セキュリティ

- FTP パスワードは AES-256 で暗号化して保存されます
- `.ftp-config.json` は Git 管理対象外です（.gitignore済み）
