# 🎬 下町きろく 管理ダッシュボード

下町きろくの動画屋サイト更新を簡単にするための統合管理ツールです。  
Claude Code内で、サイト確認、画像アップロード、コンテンツ編集、そしてさくらインターネットへの自動アップロードが全てできます。

## ✨ 機能

- **🖼️ サイトプレビュー** - 現在のサイトをリアルタイムで確認
- **📤 画像アップロード** - ドラッグ&ドロップで複数画像を一括アップロード
- **✏️ コンテンツ編集** - HTMLファイルをダイレクト編集
- **📁 ファイル管理** - 全ファイルの確認と管理
- **🚀 ワンクリック更新** - FTP情報を保存して自動アップロード
- **🔒 セキュア設定** - パスワードは暗号化して保存

## 🚀 セットアップ

### 1. 依存関係をインストール
```bash
npm install
```

### 2. 開発サーバーを起動
```bash
npm run dev
```

サーバーが起動したら、ブラウザで以下にアクセス：
```
http://localhost:5173
```

## 📝 使い方

### 初回設定（⚙️ 設定タブ）

1. さくらインターネットのコントロールパネルからFTP接続情報を確認
   - ホスト名（例：sv123.sakura.ne.jp）
   - ユーザー名
   - パスワード
   - ポート（通常は21）

2. ダッシュボードの「⚙️ 設定」タブで上記を入力して保存
   - ✅ パスワードは暗号化して保存されます
   - 🔑 以降は毎回入力する必要がありません

### 日常の更新作業

1. **🖼️ サイト確認** - 現在のサイトをプレビュー
2. **📤 画像アップロード** - 新しい画像をアップロード
3. **✏️ コンテンツ編集** - HTMLを編集して更新
4. **💾 保存** - ローカルで内容を保存
5. **🚀 さくらインターネットに更新** - ボタン1クリックでアップロード

## 🔐 セキュリティ

- FTP パスワードは AES-256 で暗号化して保存
- `.ftp-config.json` ファイルは .gitignore に含まれます
- 本番環境では ENCRYPTION_KEY を環境変数で設定してください

## 📋 API エンドポイント

| メソッド | エンドポイント | 説明 |
|---------|--------------|------|
| GET | `/api/ftp-config` | FTP設定の確認 |
| POST | `/api/ftp-config` | FTP設定の保存 |
| POST | `/api/upload-to-ftp` | サーバーへのアップロード |
| GET | `/api/files` | ファイル一覧取得 |
| GET | `/api/file/:filename` | ファイル内容取得 |
| POST | `/api/file/:filename` | ファイル内容の保存 |
| POST | `/api/upload-image` | 画像ファイルのアップロード |
| GET | `/api/preview` | サイトプレビュー |

## 🐛 トラブルシューティング

### サーバーが起動しない
```bash
# ポートが使用中の場合
lsof -i :5173
# 既存プロセスを終了
kill -9 <PID>
```

### FTP接続エラー
- ホスト名、ユーザー名、パスワードを確認
- さくらインターネットのコントロールパネルでFTP設定を確認
- ファイアウォール設定を確認

### 画像がアップロードできない
- ファイル形式を確認（JPG, PNG, GIF, WebP）
- ファイルサイズを確認
- ディスク容量を確認

## 📞 サポート

問題が発生した場合：
1. ブラウザのコンソールでエラーを確認
2. サーバーのログを確認
3. ファイルの権限を確認
